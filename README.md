# DigitalVX — Sistema de Ponto de Venda

## Sobre o projeto

O DigitalVX é um sistema de ponto de venda (PDV) desenvolvido como projeto acadêmico para a disciplina de Análise e Projeto de Sistemas.

O sistema tem como objetivo auxiliar uma gráfica na organização de seus clientes, produtos, serviços, pedidos, vendas e pagamentos, reunindo essas operações em uma única aplicação.

## Objetivo

Desenvolver uma aplicação web simples e funcional que facilite o gerenciamento das operações comerciais da gráfica, com armazenamento persistente dos dados.

## Tecnologias utilizadas

- Java
- Spring Boot
- Maven
- Spring Data JPA
- Hibernate
- PostgreSQL
- Thymeleaf
- HTML e CSS
- Git e GitHub

## Funcionalidades implementadas

- Painel inicial com indicadores.
- Cadastro, listagem e edição de clientes.
- Cadastro, listagem e edição de produtos.
- Cadastro, listagem e edição de serviços.
- Persistência dos dados no PostgreSQL.

## Funcionalidades em desenvolvimento

- Registro e gerenciamento de pedidos.
- Cálculo dos valores das vendas.
- Controle de estoque.
- Registro de pagamentos.
- Autenticação e controle de acesso.

## Execução local

1. Instale o JDK compatível com o projeto e o PostgreSQL.
2. Configure as credenciais e a conexão com o banco de dados.
3. Abra um terminal na pasta que contém o `pom.xml`.
4. Execute:

   `.\mvnw.cmd spring-boot:run`

5. Acesse `http://localhost:8080` no navegador.
